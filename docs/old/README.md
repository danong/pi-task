# Archived pi-task documentation

**Status: Historical and non-normative.** The files in this directory preserve
reviews, handoffs, investigations, plans, and superseded workflow/testing
documents for traceability. They are not current design requirements and may
describe implementation states or decisions that have since changed.

The active source of truth is the v2 design set in the parent directory:

- [`pi-task-v2.md`](../pi-task-v2.md) — product philosophy, microkernel,
  runnable MVP, context, observability, benchmarks, and evidence gates;
- [`pi-task-v2-subsystems.md`](../pi-task-v2-subsystems.md) — capability
  contracts and conformance;
- [`pi-task-v2-future.md`](../pi-task-v2-future.md) — deferred work;
- [`pi-task-design.md`](../pi-task-design.md) — active v1 compatibility and
  safety contract.

When an archived document links to a file that moved with it, the link points
within this directory where practical. References to active documents remain
references to the parent-level source of truth.
